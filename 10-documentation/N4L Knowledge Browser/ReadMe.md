## Introduction
KViz Knowledge Browser is a knowledge browser dedicated for visualizing and surfing N4L relations and N4L-documents for Hardware and Software Projects. It is aiming for providing easiness in knowledge exploring and contributing to the portability of projects documentation written in N4L.
